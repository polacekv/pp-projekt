Návod k nasazení systému

Tento průvodce vás provede celým procesem nastavení systému PP projekt pro řízení projektových zakázek. Nevyžaduje žádné technické znalosti — stačí pečlivě sledovat kroky v pořadí.

⏱
Celé nastavení zabere přibližně 20–30 minut. Doporučujeme mít po ruce počítač a přihlášený Google účet.

Co budete potřebovat

  • Google účet — pro Google Sheets a Apps Script (zdarma)
  • GitHub účet — pro hostování webu (zdarma, na github.com)
  • Soubory systému — složka, kterou jste dostali (assets/, index.html, atd.)

KROK 1 — Google Sheets (databáze)

Vytvořte novou tabulku

1

Otevřete Google Sheets

Přejděte na sheets.google.com a klikněte na velké + (Prázdná tabulka).

2

Přejmenujte tabulku

V levém horním rohu klikněte na text „Tabulka bez názvu" a zadejte například: PP projekt — databáze

Pojmenujte listy (záložky)

Systém potřebuje tyto pojmenované listy. Klikněte pravým tlačítkem na záložku List1 dole a přejmenujte ji. Pak přidejte další listy tlačítkem +.

Název listuCo obsahuje
configObecná konfigurace aplikace
projectsSeznam všech projektů
workersEvidence pracovníků a jejich odměn
financeFakturační a nákladová data
⚠️
Názvy listů musí být přesně takové — malá písmena, bez diakritiky, bez mezer. Jinak systém data nenajde.
ℹ️
Listy pro checklisty projektů (tasks_PROJEKTID) si systém vytváří sám při prvním uložení checklistu — nemusíte je vytvářet ručně.

KROK 2 — Google Apps Script (API)

Otevřete editor skriptů

1

V Google Sheets klikněte na menu „Rozšíření"

Vyberte Rozšíření → Apps Script. Otevře se nová záložka s editorem kódu.

Vložte kód

2

Smažte veškerý existující kód

V editoru uvidíte prázdnou funkci. Označte vše (Ctrl+A) a smažte.

3

Zkopírujte kód ze souboru setup/Code.gs

Otevřete soubor setup/Code.gs, zkopírujte celý jeho obsah a vložte ho do editoru Apps Script (Ctrl+V).

4

Uložte projekt

Klikněte na ikonu diskety (💾) nebo stiskněte Ctrl+S. Pojmenujte projekt například PP projekt API.

Nasaďte jako webovou aplikaci

5

Klikněte na tlačítko „Nasadit"

V pravém horním rohu klikněte na Nasadit → Nové nasazení.

6

Nastavte parametry nasazení

Klikněte na ikonu ozubeného kola vedle „Vybrat typ" a zvolte Webová aplikace. Pak nastavte:

  • Spustit jako: Já (váš Google účet)
  • Kdo má přístup: Kdokoli
7

Klikněte na „Nasadit"

Google vás možná požádá o povolení přístupu ke Spreadsheet. Klikněte na Autorizovat přístup, vyberte svůj Google účet a potvrďte (ikona „Upřesnit → přejít na PP projekt API").

Zkopírujte URL webové aplikace

8

Zkopírujte URL

Po nasazení se zobrazí okno s URL webové aplikace. Vypadá přibližně takto:

https://script.google.com/macros/s/AKfycby…ABCDEF/exec

Zkopírujte ji celou — budete ji potřebovat v dalším kroku.

Vložte URL do systému

9

Otevřete soubor assets/app.js

Najděte řádek začínající APP_SCRIPT_URL: (je hned na začátku souboru) a vložte tam vaši URL:

// Nahraďte tento řetězec svou URL:
APP_SCRIPT_URL: 'https://script.google.com/macros/s/VAŠE-URL/exec',

Soubor uložte.

✅
Teď máte funkční databázi. Google Sheets bude automaticky ukládat všechna data z vašeho projektového systému.

KROK 3 — GitHub Pages (hostování webu)

Vytvořte repozitář

1

Přejděte na github.com a přihlaste se

Pokud nemáte účet, zaregistrujte se zdarma.

2

Vytvořte nový repozitář

Klikněte na zelené tlačítko New nebo na + → New repository. Nastavte:

  • Repository name: pp-projekt (nebo libovolný název bez mezer)
  • Visibility: Public (nutné pro bezplatné GitHub Pages)
  • Nezaškrtávejte nic dalšího

Klikněte na Create repository.

Nahrajte soubory

3

Nahrajte soubory systému

Na stránce vašeho nového repozitáře klikněte na uploading an existing file (nebo Add file → Upload files). Nahrajte celou složku se systémem — tedy všechny soubory i podsložky (assets/, setup/).

⚠️
GitHub neumí nahrát celou složku jedním kliknutím. Musíte přetáhnout obsah složky (ne složku samotnou) do okna prohlížeče, nebo nahrávat soubor po souboru, přičemž podsložky musíte vytvořit ručně tlačítkem „Create new file" a zadat cestu assets/style.css apod.
4

Potvrďte nahrání

Dole klikněte na Commit changes (zelené tlačítko). Soubory se uloží.

Zapněte GitHub Pages

5

Přejděte do nastavení repozitáře

Klikněte na záložku Settings (nahoře v repozitáři).

6

Najděte sekci Pages

V levém menu klikněte na Pages.

7

Nastavte zdroj

V části Source nastavte:

  • Deploy from a branch
  • Branch: main, / (root)

Klikněte na Save.

Váš odkaz na systém

8

Počkejte na nasazení (1–2 minuty)

Po chvíli se na stránce Settings → Pages zobrazí odkaz ve formátu:

https://VÁŠE-UŽIVATELSKÉ-JMÉNO.github.io/pp-projekt/

Tento odkaz je adresa vašeho systému. Můžete ho sdílet s kýmkoli, komu chcete dát přístup.

KROK 4 — První spuštění

Otevřete systém

1

Otevřete váš odkaz v prohlížeči

Přejděte na adresu https://UŽIVATEL.github.io/pp-projekt/. Měl by se zobrazit dashboard s prázdnou obrazovkou.

2

Zkontrolujte funkčnost

Otevřete vývojářské nástroje prohlížeče (F12) a přejděte na záložku Console. Neměly by tam být žádné červené chyby s textem „Failed to fetch" nebo „Error".

Pokud chyby jsou, zkontrolujte, že jste správně zadali URL Apps Script v souboru assets/app.js.

Přidejte prvního pracovníka

3

Přejděte na stránku Pracovníci

V levém menu klikněte na Pracovníci a přidejte sebe nebo členy týmu tlačítkem + Přidat pracovníka.

Vytvořte první projekt

4

Na Dashboardu klikněte na „+ Nová zakázka"

Průvodce vás provede 4 kroky:

  1. Základní info — název, číslo zakázky, adresa, klient, HIP
  2. Tým — vyberte pracovníky z vaší evidence
  3. Fáze — zaškrtněte fáze, které bude projekt obsahovat
  4. Finance — zadejte smluvní cenu → systém automaticky vypočítá 3 faktury

Řešení problémů

Systém nefunguje / data se neukládají

  1. Zkontrolujte, že APP_SCRIPT_URL v assets/app.js je správná URL (musí začínat https://script.google.com/macros/s/ a končit /exec)
  2. Zkontrolujte, že Apps Script je nasazeno s nastavením „Kdo má přístup: Kdokoli"
  3. Systém automaticky ukládá do localStorage v prohlížeči — data tedy neztrácíte, i když API nefunguje

Po změně kódu v Apps Script se nic nezměnilo

Každou změnu kódu je nutné nasadit jako nové nasazení (ne opakovat staré). Pak zkopírujte novou URL a aktualizujte ji v app.js.

Stránky na GitHubu se neaktualizovaly

GitHub Pages má cache — po nahrání nové verze souborů počkejte 1–3 minuty a pak stránku obnovte s Ctrl+Shift+R (tvrdé načtení).

Checklist projektu je prázdný

Checklist se generuje automaticky z fází, které jste vybrali při vytváření projektu. Pokud jste projektu nepřiřadili žádné fáze, checklist bude prázdný. V takovém případě otevřete projekt na dashboardu a fáze přidejte (funkce bude přidána v budoucí verzi — prozatím projekt smažte a vytvořte znovu).

Jak sdílet checklist s pracovníkem?

Na dashboardu na kartě projektu klikněte na odkaz Checklist — zkopírujte URL z adresního řádku prohlížeče a pošlete ji pracovníkovi. Odkaz obsahuje ID projektu a přivede ho přímo na daný checklist.

Kontrolní seznam před spuštěním

  • Google Sheets tabulka vytvořena se 4 listy (config, projects, workers, finance)
  • Apps Script kód vložen a uložen
  • Apps Script nasazen jako webová aplikace (přístup: Kdokoli)
  • URL webové aplikace zkopírována do assets/app.js
  • Soubory systému nahrány na GitHub
  • GitHub Pages zapnuty, web dostupný na URL
  • První pracovník přidán do systému
  • První projekt vytvořen
